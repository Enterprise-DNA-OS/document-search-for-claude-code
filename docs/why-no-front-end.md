# Why no front end

The working record is the database. An authorised administrator asks for a search, checks the evidence and records the review through the CLI. Static branded reports show the result.

A staff portal would add authenticated identities, enforced collection permissions, mobile access and a shared search screen. This base has none of those. It also has no offline phone sync, drag and drop editor, crawler, document extraction or connector scheduling. Its audience option is a filter operated by a trusted administrator.

Enterprise DNA builds the agreed screens, source connections and access checks into your version. Keep existing staff search available until the replacement passes permission, completeness and relevance checks. Never serve the administrator database or generated reports as a public site.
