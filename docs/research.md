# Selection evidence: SearchBlox

Checked 8 November 2026. Family: enterprise-document-search. Industry hub: professional-firms. Enterprise document retrieval is separate from the existing product-catalogue search, wiki authoring and data catalogue families. Chemical inventory was already built tonight and is excluded.

The annual bill anchor is the vendor's $25,000 self-managed single-server list price. It is not an observed customer invoice. Scores: annual bill 3, data-shaped 4, our buyers 2, search demand 3, one-session buildable 4, import path 4. Total 20/30.

The customer-brain and local CRM-path search found no verified SearchBlox buyer. Buyer score is deliberately low. Search results include alternatives directories and review pages; demand is qualitative, with no measured keyword volume. No customer identity or unsupported dissatisfaction claim is used.

Other candidates considered: Freightender scores 1,4,3,2,4,4 = 18/30; its official pricing offers annual fees but publishes no amount, so it fails the annual-invoice evidence filter. Valutico scores 1,3,3,3,3,4 = 17/30; no verified current annual bill was found, and paid comparables are not an owned-data replacement. These are selection judgements, not measured market statistics.

Primary sources:

- [SearchBlox pricing](https://www.searchblox.com/pricing): self-managed single server $25,000 per year; three-server cluster $75,000 per year. Managed Hybrid Search $24,000 per year; managed plans list document and query allowances. Do not treat our smaller base as the full bundle.
- [CSV collection](https://developer.searchblox.com/docs/csv-collection): user-selected unique field, configurable input CSV settings. We reuse the authorised source CSV with explicit mapping, not a fictitious vendor export.
- [Configuration](https://developer.searchblox.com/docs/configuration): exported XML represents settings; indexing source content is a separate operation.
- [Freightender pricing](https://www.freightender.com/pricing/): no numeric annual quote.

Search demand leads, not product-fact sources: [Gartner alternatives](https://www.gartner.com/reviews/product/searchblox-enterprise-search/alternatives), [G2 alternatives](https://www.g2.com/products/searchblox-search-server/competitors/alternatives). No negative vendor claims are drawn from the reviews.

The free base supplies keyword retrieval over authorised text and evidence review. It does not reproduce all SearchBlox connectors, hybrid search, availability, identity or managed services. Scope those capabilities before cancelling an incumbent contract.
